# Sum of a list

**Exercise:** `part03-Part03_12.SumOfAList`
**Section:** Part 03 / 2-lists
**Course:** https://java-programming.mooc.fi/part-3/2-lists

## Spec

The exercise template contains a base that reads numbers from the user and adds them to a list. Reading is stopped once the user enters the number -1.

Modify the program so that after reading the numbers it calculates and prints the sum of the numbers in the list.

**72**
**2**
**8**
**11**
**-1**

Sum: 93

## Expected Output

```
**72**
**2**
**8**
**11**
**-1**

Sum: 93
```
