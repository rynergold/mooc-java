**Exercise:** `part03-Part03_16.Sum`
**Section:** Part 03 / 2-lists
**Course:** https://java-programming.mooc.fi/part-3/2-lists

## Spec

Create the method `public static int sum(ArrayList numbers)` in the exercise template. The method is to return the sum of the numbers in the parameter list.

```java
ArrayList numbers = new ArrayList<>();
numbers.add(3);
numbers.add(2);
numbers.add(6);
numbers.add(-1);
System.out.println(sum(numbers));

numbers.add(5);
numbers.add(1);
System.out.println(sum(numbers));
```

10
16

## Expected Output

```
10
16
```
