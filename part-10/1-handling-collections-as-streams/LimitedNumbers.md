# Limited numbers

**Exercise:** `part10-Part10_06.LimitedNumbers`
**Section:** Part 10 / 1-handling-collections-as-streams
**Course:** https://java-programming.mooc.fi/part-10/1-handling-collections-as-streams

## Spec

Write a program that reads user input. When the user gives a negative number as an input, the input reading will be stopped. After this, print all the numbers the user has given as input that are between 1 and 5.

**7**
**14**
**4**
**5**
**4**
**-1**
4
5
4

## Expected Output

```
**7**
**14**
**4**
**5**
**4**
**-1**
4
5
4
```
