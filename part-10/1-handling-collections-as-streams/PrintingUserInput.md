# Printing User Input

**Exercise:** `part10-Part10_05.PrintingUserInput`
**Section:** Part 10 / 1-handling-collections-as-streams
**Course:** https://java-programming.mooc.fi/part-10/1-handling-collections-as-streams

## Spec

Write a program that reads the user's input as strings. When the user inputs an empty string (only presses enter), the input reading will be stopped and the program will print all the user inputs.

**first**
**second**
**war is peace: 1984**

first
second
war is peace: 1984

## Expected Output

```
**first**
**second**
**war is peace: 1984**

first
second
war is peace: 1984
```
