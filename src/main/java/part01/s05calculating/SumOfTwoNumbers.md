# Sum of Two Numbers

**Exercise:** `part01-Part01_17.SumOfTwoNumbers`  
**Package:** `part01.s05calculating`

## Spec

Write a program that asks the user for two numbers. After this, the program prints the sum of the numbers given by the user.

- First prompt: `"Give the first number:"`
- Second prompt: `"Give the second number:"`
- Output: `"The sum of the numbers is "` followed by the sum.

## Examples

| User Input (stdin) | Expected Program Output (stdout) |
| :--- | :--- |
| <pre>8<br>3</pre> | <pre>Give the first number:<br>Give the second number:<br>The sum of the numbers is 11</pre> |
| <pre>3<br>-1</pre> | <pre>Give the first number:<br>Give the second number:<br>The sum of the numbers is 2</pre> |
