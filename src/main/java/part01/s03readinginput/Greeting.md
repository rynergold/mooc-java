# Greeting

**Exercise:** `part01-Part01_08.Greeting`  
**Package:** `part01.s03readinginput`

## Spec

Write a program that prompts the user with `"What's your name?"`. When the user provides their name, print `"Hi "` followed by the name.

## Examples

| User Input (stdin) | Expected Program Output (stdout) |
| :--- | :--- |
| `Ada` | `What's your name?`<br>`Hi Ada` |
| `Lily` | `What's your name?`<br>`Hi Lily` |

## Terminal Practice

Run the test suite from your command line:
```bash
./gradlew test --tests "part01.s03readinginput.GreetingTest"
```
