# Hi Ada Lovelace!

**Exercise:** `part01-Part01_06.HiAdaLovelace`  
**Package:** `part01.s03readinginput`

## Spec

Modify the program to concatenate and print the `name` variable with the greeting `"Hi "`.

> [!NOTE]
> Do not hardcode `"Ada Lovelace"` in your print statement. Use the existing variable `name` via concatenation: `System.out.println("Hi " + name + "!");`.

## Expected Output

| Program State | Expected Console Output |
| :--- | :--- |
| `String name = "Ada Lovelace";` | `Hi Ada Lovelace!` |
