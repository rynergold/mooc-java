# Message

**Exercise:** `part01-Part01_05.Message`  
**Package:** `part01.s03readinginput`

## Spec

Write a program that asks the user to write a string. When the user provides a string (types text and presses Enter), print the string provided by the user.

## Examples

| User Input (stdin) | Expected Program Output (stdout) |
| :--- | :--- |
| `Bye` | `Write a message:`<br>`Bye` |
| `Once upon a time...` | `Write a message:`<br>`Once upon a time...` |

## Terminal Practice

Run the test suite from your command line:
```bash
./gradlew test --tests "part01.s03readinginput.MessageTest"
```
