# Triangle Drill

**Category:** Printing Drill  
**Difficulty:** ✪ (1/7)  
**Package:** `part01.s02printing.exercises`

## Spec

Write a program that prints a 3-line ASCII triangle. 

Pay close attention to the spaces before the stars! Computers print text left-to-right, so you must use the space character ` ` to push the stars to the correct position on the screen.

## Expected Output

```
  *
 ***
*****
```
