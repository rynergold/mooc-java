# Average of a list

**Exercise:** `part03-Part03_13.AverageOfAList`
**Package:** `part03.s02lists`

## Spec

The exercise template contains a base that reads numbers from the user and adds them to a list. Reading is stopped once the user enters the number -1.

When reading ends, calculate the average of the numbers in it, and then print that value.

## Examples

| User Input (stdin) | Expected Program Output (stdout) |
| :--- | :--- |
| 1. `72`<br>2. `2`<br>3. `8`<br>4. `11`<br>5. `-1` |  |
| Program execution | `Average: 23.25` |
