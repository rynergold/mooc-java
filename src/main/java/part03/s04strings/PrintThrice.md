# Print thrice

**Exercise:** `part03-Part03_23.PrintThrice`
**Package:** `part03.04strings`

## Spec

Write a program, that reads a string from the user and then prints it three times.

Give a word: **cake**

cakecakecake

NB! The program should ask for only one string. Don't use a loop here.

## Expected Output

```
Give a word: **cake**

cakecakecake
```
