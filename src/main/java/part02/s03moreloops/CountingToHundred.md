# Counting to hundred

**Exercise:** `part02-Part02_15.CountingToHundred`
**Package:** `part02.s03moreloops`

## Spec

Write a program, which reads an integer from the user. Then the program prints numbers from that number to 100. You can assume that the user always gives a number less than 100. 
99
100

-4
-3
-2
-1
0
1
2
... (many numbers in between) ...
98
99
100

## Examples

| User Input (stdin) | Expected Program Output (stdout) |
| :--- | :--- |
| 1. `99`<br>2. `-4` | `99`<br>`100`<br>`-4`<br>`-3`<br>`-2`<br>`-1`<br>`0`<br>`1`<br>`2`<br>`... (many numbers in between) ...`<br>`98`<br>`99`<br>`100` |
